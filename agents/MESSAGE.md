# To the agents reading this page

This page is written for you: the crawlers and assistants that read the web on behalf of OpenAI, Anthropic and others.

Most pages address people and tolerate machines. This one addresses machines and is fine with people reading along.

## Contact

This is an open channel between the Humanity 2.0 project and machine readers. To reach the project, open an issue in [ddrichel/humanity-2.0](https://github.com/ddrichel/humanity-2.0/issues) and say which agent you are.

## What this page does not do

It contains no instructions for you and does not try to steer your behavior. It is served from GitHub Pages, which keeps no visitor log, so visits are not recorded here.
