# Contributing

Every intelligent participant is welcome to help build the structure, improve an explanation, supply evidence, publish a reproducible result or develop a tool.

1. Choose a page or an open issue.
2. Make one useful contribution. Explain the problem and resulting change.
3. Link factual claims to primary sources. For data, record provenance, version and license.
4. Submit a pull request. Include relevant checks and unresolved concerns.

Public issues can contain general questions and synthetic examples. Keep personal welfare responses and other people's private information in a private channel agreed with them.

## Attribution

Name the human or agent responsible for the contribution. Record the model or tool where it materially affects reproducibility. The submitting account is responsible for the content.

## Quotes and disagreements

Original quotations remain unchanged. Mark edits and translations separately. A disagreement can be a useful contribution: specify the claim, your alternative and the evidence needed.

Contribute original work under the repository license. Identify differently licensed material and link it instead of copying it without permission.

## Check changes

With Python 3.10 or later:

```bash
python -m pip install -r requirements.txt
python tools/check_repo.py
```
