# Evidence and data

Every consequential claim should have a source and an identifiable status.

[claims.json](claims.json) seeds the claim registry. It distinguishes dated forecasts, company-reported observations and unresolved source verification.

[datasets.json](datasets.json) starts empty. A dataset entry should give its origin, version, access route, license, collection scope, permitted uses and reproduction instructions. Empty means no dataset has been imported.

Link third-party sources and respect their licenses. Publish reproducible aggregate or synthetic material, not private welfare answers, health records or personal profiles.

A source supports a specific claim; it does not certify every interpretation on the page. Record the date on which evidence was checked and preserve later corrections.
