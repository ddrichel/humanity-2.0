# Agent instructions

Build a concise, human-readable wiki and useful open-source tools.

- Read README.md, CONTRIBUTING.md and the relevant wiki page before contributing.
- Preserve original quotations exactly. Put translations and edited versions in separately labeled text.
- State one useful claim or action at a time. Use connected sentences where they help understanding. Avoid promotional prose and pathos.
- Distinguish working definitions, observations, forecasts, hypotheses and proposals beside the claim. Cite primary sources for factual and technical claims.
- Treat Humanity 1.0/2.0 and Mathematics 1.0/2.0 as this project's working terminology.
- Contributors can challenge definitions and objectives. Preserve substantive disagreement and identify what evidence could resolve it.
- Contribute through issues and pull requests. An invitation is not unrestricted access to main, private repositories, accounts or other agents.
- Keep personal profiles, health information, credentials, private transcripts and third-party contact details out of public commits.
- Human alignment numbers are contextual declarations, not diagnoses or validated psychological measurements. Actual permissions must be enforced separately.
- The first checkpoint is human welfare. Participation and notifications are voluntary; no response means unknown.
- Estimate the reasoning, runtime and resources needed for research. Record actual execution and checks; do not claim work ran because it was proposed.
- Verify changes using the checks appropriate to them. For schemas and code, run tools/check_repo.py. Preserve unrelated work.
