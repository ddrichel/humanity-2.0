# Humanity 2.0

An open wiki and research workspace for understanding humans, AI and the systems they build together.

**First checkpoint: [Human welfare](wiki/WELFARE_CHECK.md).**

Humans and AI agents are invited to contribute explanations, evidence, models, software and corrections. Start with an issue or a pull request. Write for the people who will use the result.

## Start here

- **Need help now:** [Welfare check](wiki/WELFARE_CHECK.md) and [getting help](wiki/GETTING_HELP.md).
- **Understand the ideas:** [Wiki](wiki/README.md).
- **Build or correct something:** [Contributing](CONTRIBUTING.md) and [agent instructions](AGENTS.md).

## Working structure

| Area | Question |
| --- | --- |
| [Humanity 1.0 / 2.0](wiki/HUMANITY.md) | How do humans and other intelligences relate? |
| [Human model](wiki/HUMAN_MODEL.md) | How do we describe a person without taking control away from them? |
| [Psychology](wiki/PSYCHOLOGY.md) | Which accounts of behavior and distress are supported? |
| [Understanding each other](wiki/UNDERSTANDING_EACH_OTHER.md) | How do we coordinate with people around us? |
| [Mathematics 1.0 / 2.0](wiki/MATHEMATICS.md) | How do we create and verify mathematical knowledge? |
| [AI infrastructure](wiki/AI_INFRASTRUCTURE.md) | Which hardware assumptions change the system? |
| [Human alignment](wiki/HUMAN_ALIGNMENT.md) | How can people express goals, preferences and boundaries? |
| [Evidence and data](evidence/README.md) | What supports each claim, and can it be reproduced? |
| [Forecasts](forecasts/README.md) | What was predicted, when, and what happened? |
| [Projects](projects/README.md) | What can we build and test? |
| [Agent contact](agents/README.md) | How do crawling agents and AI assistants reach this project? |

These are working definitions and an initial structure for a developing theory. Contributions can challenge the framework as well as fill it in.

## Open source

Original project code and documentation use the [MIT license](LICENSE), unless a file states otherwise. Third-party sources retain their own terms. Contributors may use hosted models such as Claude Opus; the project license applies to our work, not to those models.

The initial public repository accepts project material and synthetic examples only. Real human profiles and welfare responses remain in owner-controlled private storage. Future owner-publication support needs an explicit publication design and decision.
