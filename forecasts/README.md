# Forecasts

Keep predictions separate from outcomes.

A forecast record names the speaker, original source and date, target date or horizon, predicted event, assumptions and an observable resolution rule. Preserve the original forecast when adding later evidence.

Start with [Musk and Tesla hardware](musk-hardware.md). These are dated records, not a claim to summarize every current prediction.

For a project projection, name its author and assumptions. Label calculations based on an idealized model as scenarios. They are not observations.
